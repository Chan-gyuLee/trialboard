# 프로젝트 결속 모델 정책

TEAM 모드의 PDF 에이전트와 설계 제안은 저장된 프로젝트 검토 revision, 실제 PDF SHA-256, 이용조건 revision을 정확히 결속한다. 각 모델 호출 직전에 세션·팀·역할·권한·현재 이용조건을 다시 확인하며, DB 조회를 마친 뒤에만 공급자를 호출한다. 네트워크 대기 중 DB transaction은 유지하지 않는다.

제한 공유 프로젝트와 동일 PDF 지문에서 파생된 내용은 현재 모델 작업에 보내지 않는다. 이 금지는 결속 프로젝트뿐 아니라 같은 팀 DB에서 뒤늦게 제한 공유로 바뀐 동일 지문 프로젝트에도 매 호출 적용된다. 공개·사용 허가·비민감 확인과 `external_ai=ALLOW`는 별도 조건이며, 권리나 법적 허가를 자동 판정하지 않는다.

고정 공개 TEAM 데모는 프로젝트 결속 없이 실패하도록 닫혀 있다. 명시적 합성 데모도 호출마다 세션 신원을 다시 확인한다. 이미 공급자에 전송이 시작된 첫 호출은 사후 권한 변경으로 회수할 수 없으며 후속 critique·repair만 차단할 수 있다.

이 범위는 정책 경계와 합성 테스트를 구현한 것이며 임상적·법률적 승인이나 실제 운영 보안 인증이 아니다. 연구 수집, 자동화·재시도 큐, 조건별 캐시와 FTS 보강은 `NEXT_TASKS.md`의 후속 작업이며 전체 Phase 3 완료로 간주하지 않는다.
