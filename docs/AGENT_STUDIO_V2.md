# 실행 흐름·판단 중심 결과 개편 · 2026-09-17

사용자: 에이전트가 일하는 모습이 안 보이고 결과의 의미가 이해되지 않는다. 실행·결과 디자인 전면 개편.

## 바뀐 화면

- 기존 첫 입력 화면의 색감과 글꼴 유지. 실제 앱은 `http://127.0.0.1:5173/`이며 8769 목업과 다르다.
- 실행: 수집 도구 → AI 검토·원문 대조 → MOC 계산의 3개 작업 묶음. 현재 작업을 강조하고
  옆에 최근 실제 이벤트 5개를 펼쳐 보여준다. 자료/쟁점/질문은 실제 이벤트가 전달한 것만 누적한다.
  8개 세부 상태·전체 로그는 펼침 메뉴. 독립 에이전트의 병렬 실행으로 표시하지 않는다.
- 결과: ‘이 약물의 용량 비교, 지금 설계해도 될까요?’ → 준비 상태를 쉬운 말로 설명 →
  효능/안전성 체크 → 인용 쟁점과 다음 회의 질문 → 별도 MOC 가상 비교 순서.
  COMPLETE가 임상 성공이라는 인상을 피한다. 조사 미완료/점검 실패/부분 표/AI 근거 부족이 우선한다.
  새로운 AI 요약이 아닌 저장 상태의 규칙 기반 설명. 원래 인용·출처·보고서·상세 경로 보존.
- 첫 화면에 `저장된 에이전트 실행 과정 보기` 추가. 저장 기록 GET 복구 후 재생 탭을 연다.
- 재생: 실제 저장된 이벤트의 순서·시점을 사용한다. 재생/정지/다음/처음/슬라이더.
  새 API 호출 없음, 긴 대기 축약 명시. 조사·AI 검토 이벤트만이며 PDF/계산 전체 재현은 아니다.
  검증되지 않은 저장 이벤트의 구조화 본문을 새로 노출하지 않고 스칼라 작업 알림만 사용한다.
  MOC 저장 기록에는 합성 표시를 유지한다. 재생 범위 밖의 단계는 미실행으로 단정하지 않는다.
