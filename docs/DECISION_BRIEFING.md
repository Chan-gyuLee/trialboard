1. **근거를 의심하다:** 저장된 합성 오류 기록에서 7/200 → 7/20, 3.5% → 35%를 파생한다. 수정 전후와 연결 인용을 열 수 있다. 새 모델 실행이 아니다.
2. **설계를 비교하다:** 별도의 합성 가정으로 총 60/120명 설계, 기준/변경 가정의 네 조합을 실제 로컬 계산한다. 가정 변경 시 이전 결과를 표시하고 회의 내보내기를 막는다.
3. **회의를 준비하다:** 계산 조건에 맞춘 규칙 기반 질문 3개, 담당자·후속 행동, Markdown 브리핑을 제공한다. 메모는 실행 ID별로 분리하며 재계산에 자동 승계하지 않는다.

작업 JSON에는 근거 기록, 최근 최대 4개 계산, 미완성 가정, 실행별 메모를 보관한다.
복구 시 형식·근거 digest·실행 조건/결과 연결·메모 소속을 검사한 후 명시적인 교체 확인창을 띄운다.
2 MB 한도, 알 수 없는 필드/중복 ID/외부 실행 메모/손상 결과를 거부한다. 실패 시 현재 작업을 유지한다.
