## 발표 순서

1. 공개 사례에서 85%·96%와 각 대상군/분모를 보여준다.
2. ‘비교의 허점을 검토’에서 실제 모델의 반론과 연결된 원문을 연다.
   두 값은 치료 이력별 코호트이지 두 용량군이 아니다.
3. ‘모르는 것은 보류’에서 관측 초안은 보존하고 추가 자료·회의 질문을 남긴 것을 보여준다.
4. 합성 수정 사례의 ‘피드백으로 다시 추출’에서 분모 200 → 20과 수정 근거를 연다.
   이 변화는 실제 엔진의 두 시도에서 계산하지만 **스크립트 테스트**이며 모델 성능 증거가 아니다.
5. 고정 공개 자료를 실제로 다시 실행한다. 서버에서 단계 이벤트를 받을 때 카드가 바뀌고,
   완료하면 새 실행 결과로 브리핑을 교체한다.

장기 제품 범위는 용량·프로토콜 변경·규제 미팅 검토지만, 나머지 전용 업무가 구현됐다고
발표하지 않는다. 다른 사람의 계정·동시 편집을 연출하지 않는다. ‘별도 합성 설계 실험’은
공개 발췌의 수치를 계산 가정으로 넘기지 않으며 같은 입력의 후속 분석으로 소개하지 않는다.

## 기록과 실제 실행의 구분

- 기본 공개 기록: 이전 실제 Codex 실행 `6317da69-adc3-4117-9fc5-c4dcbc890340`.
  선별된 공개 발췌 개발 사례이며 독립 평가셋/임상 정확도 측정이 아니다.
- 수정 기록: `scripts/prepare_agent_briefing.py`가 현행 엔진 + ScriptedProvider로 생성.
- 자동 재생 4.5초 간격은 발표용 속도이지 실제 모델 소요 시간이 아니다.
- 작업 단계는 독립된 여러 전문가가 아니며, 내부 사고 과정이 아닌 작업 산출물이다.
- JSON reader는 3.2 계약·입력 hash·관측/시도 연결을 검사한다. 작성자 인증이나 원문 PDF 대조는 아니다.
- 가져온 기록은 브라우저 메모리에만 남는다. 새 실행은 현재 브리핑을 교체하므로 먼저 저장한다.
- 취소·실패·연결 끊김을 저장 성공 예제로 자동 대체하지 않는다.

## 로컬 실행

화면: `http://127.0.0.1:5173/`.

```bash
uv run python -m trialboard.api --enable-designs --enable-agent-demo
```

- `--enable-agent-demo`를 켜야 POST 경로가 생긴다. 기본 API에는 모델 실행 경로가 없다.
- 체크박스 동의 후 고정 `public` 또는 `synthetic` 자료만 보낸다.
- 공식 Codex CLI의 기존 ChatGPT 로그인 adapter 재사용. 인증 파일 직접 읽기,
  대회/API 키 사용, 임의 프롬프트·모델·URL·PDF 전송 경로를 추가하지 않았다.
- 공개 자료: 추출 + 반론 최대2요청/수정0회. 발췌에 없는 정보를 반복 추출로 채우지 않는다.
  합성 자료: 최대4요청/수정1회. 전체120초, 클라이언트 대기135초.
- 동시1실행/프로세스, loopback 전용, Origin 검사, 취소 시 CLI 정리 후 슬롯 반환.
  영구 작업 저장소는 없고 이미 소비한 사용량 환불을 보장하지 않는다.
- 이벤트에는 단계와 관측·쟁점·질문 개수만 포함한다. reasoning/원시 CLI 진단은 노출하지 않는다.
- 공식 실행 안내: https://learn.chatgpt.com/docs/non-interactive-mode
  개인 로그인 경로를 기업 인증·공개 서버에 적용하지 않는다.
