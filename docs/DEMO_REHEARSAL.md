# 재현 가능한 합성 설계 시연

이 절차는 **가상 데이터·스크립트 응답·자동 생성된 확인 이력**을 사용한다.
실제 AI의 정확도, 사람의 원문 확인, 전문가 의견, 임상 타당성 또는 최종 평가 점수가 아니다.
PDF 첫머리·파일명·모델 실행 모드·필드 수정 사유에 합성/자동 테스트임을 명시한다.

## 생성과 자동 연결 검사

1. 저장소에서 `uv run python -m trialboard.api --enable-designs`를 실행한다.
2. 별도 터미널에서 `cd web` 후 `npm run dev`를 실행한다. Node 24를 사용한다.
3. 저장소에서 합성 PDF를 만든다. reportlab은 이 명령의 임시 환경에만 설치한다.

```bash
uv run --with reportlab python scripts/create_design_demo_pdf.py
```

출력한 절대 PDF 경로를 다음 명령의 인자로 넘긴다.

```bash
cd web
node scripts/check-design-workflow.mjs /absolute/path/to/SYNTHETIC-DEMO-NOT-CLINICAL.pdf
```

생성기는 `output/pdf/design-demo-<새 ID>/`를 만들며 기존 파일을 덮어쓰지 않는다.
연결 검사는 같은 폴더의 파일이 이미 있으면 멈춘다. 다시 하려면 새 PDF 폴더를 생성한다.
서버는 저장하지 않으며, 이 스크립트만 합성 시연 결과를 로컬 파일로 저장한다.

검사 항목:

- 실제 렌더링 가능한 한 페이지 PDF의 PDF.js 추출·좌표와 관측값 4개.
- 스크립트 추출 결과 → 웹 검토 → JSON 복구의 동일성.
- 브라우저용 요청 생성 코드 → Vite 프록시 → opt-in Python API → 웹 결과 검증.
- 2설계 × 2가정 = 계산 4개, 일반/비교 KOL 질문 8개.
- 회의 메모 기록 → JSON 내보내기 → 복구.
- 같은 검토에서 관측값 하나를 사용자 보류하면 계산 0개·선결 질문 생성.
- 모델 호출 0회. API 키/현재 Codex 모델 사용량을 소비하지 않는다.

생성 파일은 PDF, source-export.json, original-agent.json, review.json, design-brief.json,
report.json, meeting.json/meeting.md, held-review.json/held-brief.json/held-report.json,
렌더링 검사용 PNG, workflow-check.json이다. 원본/이력은 JSON에 포함된다.

## 사람이 화면에서 따라 하기

1. 로컬 웹 → 자료 검토 → PDF → 생성된 **SYNTHETIC-DEMO-NOT-CLINICAL.pdf** 선택.
2. 필드 검토 → 저장한 검토 이어하기 → `review.json` 선택.
3. 설계 비교·KOL → 회의 JSON 이어하기 → `meeting.json` 선택.
4. 결과 비교에서 plateau/모든 군 한계 초과 가정을 번갈아 본다. 후자에서는 올바른 보류와 실제 용량 선택을 혼동하지 않는다.
5. KOL 회의에서 통계 질문의 기존 추가 확인 메모를 읽고 답변/담당자/다음 행동/사유를 수정·기록한다.
6. 회의 JSON/Markdown을 내려받는다. JSON은 같은 PDF와 검토를 복구한 다음 이어할 수 있다.
7. 설계 입력으로 돌아와 군당 표본수를 바꾸면 기존 결과가 숨겨지는지 확인한다.
8. 로컬 계산에서 `original-agent.json`을 연결하고 전송에 동의한 뒤 재계산한다. 기존 회의 기록 교체 안내를 확인한다.
9. 필드 검토에서 `held-review.json`을 복구하고, 설계 입력의 `held-brief.json`을 불러온 후
   `held-report.json`을 가져오면 계산 차단·원문 복귀·KOL 선결 질문이 보여야 한다.

2026-09-14 자동 절차는 통과했고 생성 PDF 렌더링도 육안 확인했다.
권한 적용 후 로컬 스크린샷·합성 PDF 업로드/렌더링·문구 추출·필드 검토 진입을 확인했다.
검토 JSON을 선택하는 macOS 경로 창 제어가 반복해서 어긋나 복구 이후 클릭은 미검증이다.
앱 복구 오류로 확정하지 않았으며 위 체크박스는 여전히 미완료다.
PDF 세션 종료 경고는 브라우저가 생략할 수 있으므로 자동 백업으로 취급하지 않는다.
필드 검토와 회의 JSON은 별도 파일이며 원문 메모와 결과 생성 전 설계 입력도 따로 보관한다.
수정 후 화면에서 경고 취소 시 자료 유지, 원문 메모 버튼의 원문 탭 이동을 추가 확인한다.
서버·Vite를 종료하려면 각 실행 터미널에서 Ctrl-C를 누른다. Git/사이트 배포와는 별개다.
