# 시간 기준 최종 평가 — 실행은 마지막, 분리 원칙은 먼저

2026-09-14 팀 요청 반영. 아직 최종 평가 데이터셋·cutoff 날짜·정답을 구성하거나 성능을 측정하지 않았다.
개발 중 사용한 FDA 사례와 합성 자료의 결과를 시간 분할 최종 성능으로 표시하지 않는다.

## 지금 고정할 원칙

- 먼저 검토 질문과 평가 단위(시험/자료/관측값/설계 결정), 자료 공개 시각 기준, cutoff와 허용 입력 범위를 정한다.
  구체적인 날짜는 사례/자료 선정 때 별도로 확정하며 현재 임의의 날짜를 소급 설정하지 않는다.
- 입력 스냅샷에는 cutoff 당시 공개된 버전만 포함한다. 현재 갱신된 웹페이지의 과거 날짜만 믿고 쓰지 않는다.
- 동일 시험/약물의 중복 문서와 결과 업데이트는 그룹으로 관리한다. 문장 단위 무작위 분할로 중복이 섞이지 않게 한다.
- cutoff 뒤 결과/발표는 블라인드 평가용으로 격리한다. 프롬프트·가정·설계 규칙을 튜닝하는 데 보지 않는다.
- 이미 개발자/모델 입력에서 본 사례는 개발용으로 표시한다. cutoff 분할만으로 모델 사전학습 오염이 제거됐다고 주장하지 않는다.
- 결과를 연 뒤 변경한 구현은 같은 평가셋에서 독립 최종 평가로 재주장하지 않는다. 실패와 변경을 따로 남긴다.

## 마지막에 실행할 것

독립 검토자가 원문 추출/분모/집단/시점/인용/적절한 보류를 평가하고, 설계 가정과 질문의 실무 유용성은 별도로 평가한다.
가능하면 같은 모델·입력·예산의 기준선과 비교하며, 추출 정확도와 미래 시험 결과 예측력을 섞지 않는다.
제출 전 source hash·공개/수집 시각·버전·cutoff·split 사유·코드/모델/프롬프트·실패 사례를 묶어 기록한다.
이 문서는 평가 절차 초안이며 독립 임상 검증이나 시간 분할 데이터셋 완성의 증거가 아니다.
