2026-09-16. 사용자 요청: 다음 작업 진행 + 최종 결과가 한눈에 들어오도록 개선.

## 구현

- 결과 첫 화면을 약물/시험 → 판단 범위 한 문장 → 효능·안전성·설계 상태3카드 → 다음 판단 순서로 변경.
  자료/쟁점/질문 개수는 작은 보조 지표로 내렸다. 임상적 결론이 아닌 등록 결과 준비 상태의 규칙 요약이다.
- `result-summary.ts`: 근거 없음/복구 실패/부분 표시/AI 미완료를 구별한다.
  안전성 후보만 있으면 용량별 효능 근거 보완, 둘 다 후보여도 적용 범위 확인을 요구한다.
  MOC9조합 계산을 실제 근거 기반 설계 완료로 표시하지 않는다.
- 결과 본문 MUI탭3개: 설계 비교·다음 판단 / 근거·AI 검토 / 원문·처리 기록.
  기존 등록표/인용/질문/PDF 페이지/추출·선정 기록은 삭제하지 않고 필요한 탭에서 보여준다.
- 설계 기준 전환: 군당20/40/60명 중 기준을 변경하면 다른 안의 추가 참여자 수, 올바른 선택/보류 %p 차이,
  독립 난수 계산 기준 차이의 Monte Carlo SE를 표시. 최대값을 추천하거나 유의성/검정력을 추론하지 않는다.
  저장된 결과만 계산하며 모델/네트워크/시뮬레이션 재실행 없음. 원본 가정과 보고 값 불변.
- 핵심 KOL 질문은 기존 AI 질문 앞3개를 원문 그대로 표시한다. 새 우선순위 추론이나 전문가 의견이 아니다.
- 보고서도 규칙 요약/다음 판단부터 시작한다. 모든 기존 근거와 MOC 계산을 포함하며 설계 차이도 추가.
  보고서 비교 기준은 군당20명으로 고정이라고 명시한다. 화면 선택을 보고서에 반영한 것으로 사칭하지 않는다.
- Sites 스킬의 정보 우선순위·기존 구성 유지 원칙 적용. MUI탭/ToggleButton 재사용, 새 의존성·이미지·배포 없음.
