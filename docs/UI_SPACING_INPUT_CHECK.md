# 화면 간격·전송 전 원문 준비 점검

2026-09-16. 기존 MUI를 유지한 로컬 UI 개선. 전체 진행률77%/기업25% 유지.

## 구현

- 공통 배너 본문/동작 사이12px, 좁은 화면에서 동작을 다음 줄로 배치. 모바일 버튼 최소 높이44px.
- PDF 에이전트 패널의 직접 자식 간격20px. 수집·조사·설계·관측 범위 배너의 인접 간격16–20px.
- 확인창 설명→배너16px, 동작 버튼 사이12px. 수집 맥락의 연속 입력란 사이20px.
- `PdfInputCheck`: 실제 전송 대상으로 구성된 문구에 시험명·약물명·숫자/%·분모 표현·기간 표현이 있는지 로컬에서 검사한다.
  선택한 시험 맥락을 원문 근거로 대신하지 않는다. 여러 NCT 번호 경고, 설명 펼치기, 발견 문구의 PDF 위치 이동.
  `95% CI` 등 명시적 신뢰수준을 관측 비율로 세지 않는다. 분리된 표 수치·단위를 합치거나 숫자를 생성하지 않는다.
- 수집 출처로 돌아갈 때 ‘저장 기록 여는 중’을 새 검색 진행과 구분. 새 모델 호출/외부 검색/DB 스키마 변경 없음.
