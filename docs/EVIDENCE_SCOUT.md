# 약물명으로 시작하는 공개 근거 수집

2026-09-15. 예선 제안서의 Evidence Scout/근거 저장을 현재 코드에 연결한 첫 단계.
기존 PDF 검토 기능과 분리된 실제 공개 검색이며 MOC나 LLM 실행이 아니다.

## 사용자 흐름

1. 첫 화면에서 공개 약물명·개발 코드 또는 NCT 번호 입력.
2. 공개 검색어의 외부 전송과 로컬 저장을 확인하고 수집 시작.
3. 실제 검색 요청 → 수신·구조화 → 저장 → 완료 이벤트 표시.
4. 관련 시험을 선택해 중재·시험군·주요 평가변수·등록 모집 수와 갱신일 확인.
5. 약물명과 적응증 확인 후 PDF 검토로 이동. PDF 에이전트에서 ‘검색 맥락 적용’은 별도 클릭.
   등록정보와 PDF가 동일한 시험인지는 사람이 확인한다. 이미 생성한 모델 기록은 덮어쓰지 않는다.
6. 최근 수집 기록은 SQLite에서 다시 열기. 재검색이나 모델 호출 없음.

## 실행 및 저장

```sh
uv run python -m trialboard.api --enable-designs --enable-agent-demo --enable-pdf-agent --enable-evidence-scout
```

- 기본 비활성화. 기존 loopback/origin/body 경계를 유지한다.
- 검색원: [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/api).
  약물은 `query.intr`, NCT는 `/studies/{NCT}`의 정확한 ID 조회.
- 한 번 최대 20건, 한 외부 요청, 4 MB 응답·25초 제한, 동시 수집 1개. 자동 재시도/전체 페이지 수집 없음.
- NDJSON 단계 이벤트. 웹은 순서·검색어 일치·개수·출처 URL·자료 형태·5 MB 전체 응답을 검증한다.
- `output/evidence/trialboard.sqlite3` (Git 제외)에 원본 JSON 스냅샷(SHA-256)과 수집 기록 저장.
  동일 원본은 중복 저장하지 않고 실행 기록은 각각 보존한다. 변경 원본도 이전 기록을 덮어쓰지 않는다.
- 현재 DB는 로컬 공개 등록자료 저장소다. 기업 공유 DB·사용자 계정·권한·보존 정책이 아니다.
- 시험 선택/검토 맥락은 현재 탭 메모리다. PDF·설계·회의 작업은 기존 JSON 보관 정책을 유지한다.
- 저장 기록 JSON은 구조화 자료·출처·원본 hash를 포함한다. 원본 전체 JSON은 로컬 DB에 보존한다.

## 구현한 것과 아직 아닌 것

- 약물명 검색은 동일 약물 확인/별칭 지식 그래프를 완성한 것이 아니다. 비관련 시험·병용·건강인 시험도 포함될 수 있다.
- 최대 20건의 부분 수집을 명시한다. 검색 총 건수와 실제 저장 건수를 혼동하지 않는다.
- 등록 모집 수는 분석집단 분모가 아니다. 등록 시험군은 새 설계안이 아니며 자동 확률 추정에 사용하지 않는다.
- 공개 문서의 등록 메타데이터 개수만 확보. 프로토콜/SAP 원문, PubMed/EuropePMC 논문, FDA 검토문서 자동 수집은 다음 단계.
- 원본 수집 이력은 있으나 문서 버전/변경/결과의 trial lineage 및 교차 출처 충돌 탐지는 미구현.
- 비공개 후보물질 정보·기업 기밀·환자 자료를 검색어에 넣지 않는다. 대회 API/모델 인증은 사용하지 않는다.

## 검증 기록

- Python 새 테스트 19개: opt-in, 동의/입력/origin, 단계/복구/중복 원본/변경 보존,
  오류·빈 결과·정확한 외부 호스트/검색 파라미터, redirect/크기/JSON 제한.
- 웹 새 테스트 14개: 분할 UTF-8, 이벤트 순서/누락/중복, 잘못된 출처·개수·검증 주장·검색어/응답 크기 차단.
- 실제 Chrome: NCT03600883 한 건 수집, sotorasib 일치72건 중20건 수집·저장.
  새 API 프로세스에서 기존 NCT 기록을 다시 열고 약물명 확인 후 PDF 화면의 선택 맥락 확인.
- 390px 첫 화면 가로 넘침 없음. 전체 접근성·모든 결과/실패 UI·검색 맥락 적용 후 실제 PDF 모델 실행은 미검증.
- 최신 전체 테스트/서버 PID는 SESSION_HANDOFF를 참조. 커밋/push/사이트 배포와 새 모델 호출 없음.
