# 다중 출처 조사 에이전트와 근거 DB

2026-09-15. 로컬 구현/실행 기록. 공개 자료만 사용하며, 임상적 의사결정이나 전문가 검증 완료를 뜻하지 않는다.

## 지금 실제로 이어지는 흐름

약물명 → 공개 등록정보 검색 → 시험·약물·적응증 확인 → 다중 출처 수집 →
선택적 AI 조사 계획 → 실제 후속 검색 → 인용 연결 검토·KOL 질문 → 근거 DB 탐색·판단 이력 → 공개 PDF 원문 검토.

- ClinicalTrials.gov: 선택 NCT의 최신 등록정보, 참고문헌 PMID, 공개 프로토콜/SAP 문서 링크.
- Europe PMC/PubMed: 등록부 인용 PMID, NCT 검색, 약물명 검색을 별도로 실행한다. 초록/서지 자료이며 논문 전체 본문 수집은 아니다.
- Drugs@FDA: 성분명으로 신청과 공개 label/letter/review PDF 링크를 찾는다. 약물 단위 자료이지 선택 시험 결과임을 보증하지 않는다.
- 현재 Codex 로그인 모델: 첫 호출로 우선 자료·후속 검색어를 결정, 수집기가 추가 검색을 실행, 두 번째 호출은 새 근거를 포함해 검토한다.
- UI는 실제 작업 이벤트·경과시간·초기 계획·최종 브리핑을 표시한다. 내부 사고 전문/가짜 타이핑/스크립트 결과를 실제 AI로 표시하지 않는다.

## 명시적인 범위와 제한

공개 수집과 모델 전송은 별도 동의다. 대회 키 사용/인증 파일 접근/다른 공급자 fallback 없음.
모델 최대2요청, 모델 요청당85초·전체240초. 기존 고정/PDF 모델 경로와 동시 슬롯1을 공유한다.
논문 검색당20개, 등록부 참고 PMID20개, 저장 근거100개, FDA 신청3개·신청별 최신 문서 항목12개.
서지 응답당4MB, 공개 PDF5MB. 고정 호스트·경로만 허용하며 redirect/임의 URL 프록시는 거부한다.
초록/등록 문구 최대18,000자, 계획 입력은 최대24개×650자, 최종 검토는 최대8개×4,500자다.
후속 검색에서 새로 확보한 최대2개 출처를 최종 검토 입력에 예약한다. 전체 문헌고찰이 아니다.

PDF는 버튼을 눌러 내려받기 전까지 `PDF_AVAILABLE`이다. 다운로드한 바이트를 DB에 보관하고 SHA-256을 웹에서 재대조한다.
같은 조사·문서는 다시 열 때 저장 바이트를 재사용한다. 기존 PDF.js 뷰어는40페이지 제한이다.
PDF를 다운로드/열었다는 사실은 AI가 본문을 전부 읽었다거나 임상적으로 검토했다는 뜻이 아니다.

## 출처와 버전 보존

`output/evidence/trialboard.sqlite3` — Git 제외. 원문 응답·공개 문서와 개인의 비민감 검토 메모를 저장한다.

| 테이블 | 역할 |
| --- | --- |
| snapshots / searches | 원본 응답 SHA-256 중복제거 / 최초 등록정보 검색 영수증 |
| research_runs | 조사 맥락·단계 이벤트·모델 호출 기록·상태·초안 |
| source_versions / research_sources | 출처별 정규화 내용 버전 / 조사별 사용 버전 |
| research_links | PMID 인용·NCT 언급·약물 검색 등 연결 근거와 원본 스냅샷 지문 |
| source_fts | 제목·초록·등록 문구의 조사/버전별 FTS5 검색, 모델·외부 요청 없음 |
| public_pdf_blobs / public_pdf_receipts | 공개 PDF 바이트의 지문 / 조사·문서 연결 |
| research_curation | 출처/지문에 묶인 추가 확인·포함·제외 판단과 append-only 수정 이력 |

내용 지문은 수집시간·검색 경로를 제외해 새 수집 자체를 원문 변경으로 오인하지 않는다.
이전 동일 프로젝트 대비 추가/내용 변경/이번 미수집을 분리한다. 미수집은 삭제가 아니며, 정규화 내용 변경은 프로토콜 amendment 판정이 아니다.
FTS 결과는 해당 조사의 source version에 한정된다. 의미 임베딩/RAG·다중 사용자 인증·기업 협업 DB는 아직 아니다.
검토 이력 저장은 expected_revision 충돌 검사(409)를 하며 원문과 AI 초안을 수정하지 않는다.
표시명은 인증된 사람/전문가가 아니다. 판단에 따른 AI 재검토·설계 재검증은 아직 자동 연결하지 않았다.
프로세스 강제 종료 시 RUNNING 기록이 남을 수 있다. 이를 실제 백그라운드 실행/완료로 간주하지 않는다.

## 원문 근거의 한계 표시

검색 일치 / 등록부 BACKGROUND·DERIVED 인용 / 초록의 NCT 명시를 구분한다. 어느 것도 동일 분석집단 검증을 자동 보증하지 않는다.
AI 인용문이 실제로 제공한 부분 문구에 없으면 검토 초안을 차단하고 수집 자료는 보존한다.
문자열 일치는 해석의 임상 타당성 검사가 아니다. AI 설명에 선택 NCT가 있지만 확보 출처 문구에 NCT가 없으면
화면과 Markdown에 별도 연결 미확인 경고를 붙인다. 초기 계획의 부족한 근거와 최종 검토 결과도 구분한다.
확정되지 않은 초록 수치를 자동으로 설계 확률·권장 용량으로 전환하지 않는다.
