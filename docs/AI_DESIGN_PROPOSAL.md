# 검토 근거 → AI 설계 초안 → 사용자 확인 → 계산

2026-09-22. 공개 검색 전체를 자동 임상 설계로 바꾸는 기능이 아니라,
**이미 검토한 한 PDF의 관측값에서 연구용 설계 가정을 제안하는 첫 연결**이다.

## 사용 흐름

1. 로컬 API를 `--enable-designs --enable-pdf-agent`와 대회 모델 설정으로 시작한다.
2. 자료 검토 → PDF 원문 확인 → 추출 결과와 필드 검토를 연결한다.
3. `04 설계 비교·KOL`의 **AI 비교 초안 제안**에서 목표·군당 최대 인원을 확인하고 외부 전송에 동의한다.
4. 실제 단계 이벤트: 근거 재검증 → 모델 제안 요청 → 제안 조건 검사.
5. 표본수 2안·민감도 2–3가정·제안 이유·관측값 링크·추가 질문을 확인한다.
6. 초안을 입력으로 가져온다. 기존 입력이 있으면 교체를 확인한다.
7. 현재 가정·표본수·가중치·한계를 확인한 뒤 별도 로컬 계산을 실행한다.
8. 계산 결과와 KOL 의제는 기존 비교·회의 화면에서 확인한다.

합성 예제로 점검할 때는 MOC PDF → MOC 추출 기록 → MOC 검토 예제 순으로 연다.
검토 복구 시 같은 원본 실행 hash가 연결되어 있으면 그 파일을 보존한다.
합성 자료·자동 생성 확인 이력은 실제 임상 자료/전문가 확인으로 소개하지 않는다.

## 구현과 안전 경계

- `/api/design-proposals`: 단일 모델 호출 SSE, 설계+PDF 두 옵션을 켠 경우만 활성화.
- 대회 API 또는 명시 선택한 Codex만 사용. 키는 기존 서버 설정을 재사용하고 브라우저에 보내지 않는다.
- 로컬 Origin·명시적 동의·24MiB 요청/5MiB PDF·공유 모델 슬롯·120초·출력6,000토큰 한도.
- 자동 재시도/공급자 전환/파일 영구저장 없음. 종료·연결 끊김 시 작업 취소/슬롯 해제.
- 제안 전 원문 hash·검토 이력·확인된 관측값을 재검증한다. 서로 비교할 2–4개 용량군,
  반응/이상반응 근거와 문맥이 부족하거나 기존 비교 제한이 있으면 모델을 호출하지 않고 보류한다.
- 모델이 `NEEDS_EVIDENCE`를 반환할 수 있다. 없는 ID·인원 제한 초과·잘못된 확률/차원·추가 승인 필드는 거부한다.
- `ai_proposed_hypothetical` 출처에 제안 ID·참고 관측값 ID·입력 확인 digest를 보존한다.
  사용자 지정 가정(`user_declared_hypothetical`)으로 세탁하지 않는다.
- AI 응답의 확인 digest는 항상 null. 가져오기는 확인이 아니다. 명시적 확인 후에만 계산 가능.
  표본수/확률/근거/난수 설정 등 어느 입력이든 바뀌면 기존 확인은 무효가 된다.
- 확인 digest는 모든 입력을 IEEE-754 숫자 정규화 후 묶는다. Python/JS의 1.0/1·지수 표기 차이를 회피한다.
  **사용자 신원 인증/전자서명/임상 승인은 아니다.** 사용자가 직접 편집한 로컬 JSON의 진위도 보증하지 않는다.
- 서버는 실제 계산 시 근거와 확인을 다시 검사한다. 저장·복구·회의 내보내기에도 AI 출처가 남는다.

## 확인한 범위

- 최종 전체 Python708/웹946 테스트, Ruff/TypeScript/웹 빌드 통과.
  병렬 검증 중 기존 Codex subprocess 정리 검사에서 macOS `killpg` PermissionError가 한 번 발생했다.
  해당 검사 단독 및 전체 재실행은 통과했다. 이번에 수정하지 않은 간헐 이슈이며 해결됐다고 주장하지 않는다.

- 합성 계약 검사: 모델 응답·보류·잘못된 인용·입력 변경·취소·타임아웃·전송 동의·동시 호출 제한.
- Python/JS 왕복: 확인 digest 일치, 미확인 계산 차단, 확인 후 실제 엔진 계산, 저장/복구.
- 실제 대회 `gpt-5.6-terra` 두 번 호출(합성 자료만):
  - 엔진 연결 검사: 2안×3가정 생성, 테스트용 입력 확인 후 6조합 계산. 입력2,705/출력1,645토큰.
  - 실제 브라우저: MOC PDF/기록 → 대회 제안 1회 → UI 가져오기/확인 → 로컬 6조합 → KOL 탭.
    이후 표본수 편집 시 확인 무효화 확인. 1440×1000/390×844, 콘솔 오류0/모바일 가로 넘침0.
- 브라우저 생성물은 로컬 `output/proposal-qa/`에 있으며 Git 제외.
- API는 최신 코드로 재시작했으며 키/DB/영상은 변경하거나 Git에 넣지 않았다.

## 아직 하지 않은 것

- 약물명 검색→여러 실제 문서→검토된 관측값→설계 제안까지 자동 완주.
- 독립 전문가가 평가한 실제 약물 설계의 임상적 타당성/수치 정확도.
- 다중 문서·표/각주·코호트·평가 시점의 신뢰할 수 있는 자동 정렬.
- PK/PD, 적응형 설계, 검정력 계산, 규제 승인 예측, 최적 용량 추천.
- 기업용 인증/권한/공동 승인, 제안 전체의 자동 DB 저장 및 버전 간 영향 추적.
- 기존 Codex subprocess 정리의 간헐 macOS 권한 오류 원인 조사(대회 API 경로와 별개).

다음은 실제 공개 자료 한 사례에서 입력·원문·제안 이유를 대조하는 제한적 평가다.
근거 부족 보류를 제거해 성공처럼 보이게 하지 않는다.
