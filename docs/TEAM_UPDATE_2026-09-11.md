## 오늘 한 일

1. **제품 방향과 제안서 정리.** 범위를 표적항암제 용량 비교시험 준비로 좁혔다. 결과물은 근거표, 설계 비교, 가정별 계산, 전문가 검토 브리프다. 최적 용량·승인 확률을 자동 확정하지 않는다. 개정 제안서는 준비용 초안이며 제출하지 않았다.
2. **기존 구현 정리와 새 검토 엔진.** 사용자의 요청대로 이전 수집·그래프 코드를 제거하고 새 실행 경로를 만들었다. 출처 hash·버전·문맥·사건 수·분모를 대조하고, 정상·분모 오류·자료 결측을 구분한다. 과거 코드는 Git 이력에 남아 있다.
3. **공개 FDA 원문 확인.** 승인서한과 용량 최적화 지침에서 근거 5개를 원문 4페이지의 강조 위치와 연결했다. 고정된 원문에서 지정 문구가 정확히 발견되는지 검사한다. 문구의 존재 확인과 임상적 의미 검증은 다르다.
4. **가정 실험과 로컬 API.** 두 용량군·두 표본수의 합성 시나리오를 고정 seed로 계산한다. 로컬 화면에서 가정을 바꿔 재계산하고 이전 결과와 비교·내보내기할 수 있다. 요청 크기·계산량·동시 실행 제한을 넣었다.
5. **사용자 흐름과 화면 재구성.** 사용자가 “무엇을 입력하고 어떤 결과를 보는지 모르겠다”고 해서 첫 화면을 시뮬레이션에서 자료 검토로 바꿨다. 지금은 `CSV 선택 → 내용 확인 → 질문 선택 → 검토 → 원본 행 확인·내보내기`다. React·TypeScript·Material UI를 사용했다. MUI는 Material Design 기반 라이브러리이지 Google이 제공하는 공식 컴포넌트는 아니다. 디자인은 최종 승인 전이다.
6. **로고 두 방향 탐색.** 1안은 심볼+이름, 2안은 워드마크였다. 사용자가 두 방향을 승인하지 않았고, 특히 2안은 요청한 심볼 로고가 아니었다. 둘 다 기록만 남겼으며 사이트에 적용하지 않았다.
