# 저장 재검토 사용량 화면

개인 계정 개발. 서버 계약은 `RESEARCH_REVIEW_USAGE_CONTRACT_2026-10-01.md`를 따른다. 대회 API 실호출·영상 변경·배포·실사용 DB 수정은 하지 않았다.

## 표시 범위와 디자인

기존 저장 자료 재검토 패널에 읽기 전용 요약을 추가했다. frontend-design에 따라 기존 글꼴·색상·왼쪽 정렬과 반응형 배치를 유지했다. 새로운 장식·그래프·사용률 막대를 추가하지 않는다. 이 집계는 한 조사의 저장 재검토에 한정되며, 제품 전체 비용이나 대회 잔여 한도로 오해하지 않도록 설명한다.

- 시작·종료 레코드를 중복 계산하지 않는다. 실제 공급자 DACON_RESPONSES와 SCRIPTED_TEST_DOUBLE을 별도로 표시한다.
- 토큰이 응답에 없으면 0으로 확정하지 않고 방향별 미확정 건수를 표시한다. 종료 기록이 없으면 호출·토큰을 합계에서 제외하고 실제 사용량이 더 클 수 있다고 안내한다.
- 조회 시점과 완료·실패·중단 건수를 표시한다. 자동 재시도나 공급자 잔여량 조회는 하지 않는다.
- 출처·실행 기록 새로고침과 검토 종료 후 집계를 다시 읽는다. 조회 권한 회수·실패 시 이전 숫자를 남기지 않는다. run 변경/닫기의 늦은 응답은 폐기한다.
