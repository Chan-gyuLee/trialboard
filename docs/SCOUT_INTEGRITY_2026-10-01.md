# 초기 시험 검색 무결성 보완

개인 계정 개발의 마지막 좁은 보정이다. 기존 공개 검색 동의 계약을 유지하며, 초기 EvidenceStore 검색에 research RAW 정책을 자동 적용하거나 새 이용허가를 추정하지 않는다. 실 외부 검색·모델·실사용 DB 변경은 없다.

## 발견 및 수정

- TEAM 검색 도중 세션을 철회해도 저장·COMPLETE 응답이 이어지는 합성 재현을 확인했다. 요청 시점뿐 아니라 수집 후, 저장 transaction 안, 결과 반환 전에도 실제 인증 주체·역할을 다시 확인한다. 조회도 읽기 전후 권한을 재확인한다.
- NCT 번호 검색에 다른 시험의 응답을 받아들이는 경우를 서버와 브라우저에서 거부한다. 진짜 빈 검색 결과는 허용한다.
- 기존 EvidenceStore는 저장된 원본과 receipt를 다시 해시 검증하지 않았다. 이제 읽기 전용 SQLite snapshot에서 원본 canonical SHA, 행 ID/시각/digest와 receipt 결속을 확인한다. 새 기록에는 별도 불변 receipt 지문을 저장하며, 기존 기록은 원본에서 재구성 가능한 필드를 대조한다.
- 브라우저 NDJSON은 중복 키·prototype 키·비유한 수치를 허용하지 않는 기존 엄격 JSON reader를 사용한다. 이벤트 순서와 전체 응답 크기 제한도 유지한다.

## 검증과 한계

서버 검증은 `tests/test_scout_integrity.py`, 브라우저 검증은 `web/tests/evidence-scout.test.mjs`다. 실제 TEAM 라우트에 임시 DB·가짜 공개 응답을 연결하고, 반환된 stream과 저장 receipt를 브라우저 reader로 대조한다. 외부 모델 호출은 없다.

구형 receipt에는 당시 검색어 자체를 증명하는 독립 지문이 없으므로 모든 과거 변조를 증명할 수 없다. 새 지문도 데이터베이스 전체를 교체할 수 있는 관리자에 대한 전자서명·보안 인증은 아니다. 초기 검색 자료의 목적별 이용조건 모델은 별도 미완료이며, 공개 검색 동의와 research 수집 원본의 개별 허가는 구분한다.

구현 중 `save` closure의 지역변수 참조 오류가 실제 서버→TS 시험에서 검출됐다. 인자 전달로 수정하고 정상 왕복을 재검증했다. 중간 실패는 최종 통과 기록으로 숨기지 않는다. 전체 최종 수치와 상태는 `SESSION_HANDOFF.md`를 따른다.

최종 보정 19개는 부모 독립 실행에서도 모두 통과했고 자식 관련 통합89개도 통과했다. 먼저 시작한 전체 실행은 보정 전 테스트 fixture를 로드해 TEAM 임시폴더 권한 오류 2개/1034통과를 냈다. 폴더를0700으로 준비하도록 시험만 수정한 상태에서 전체 회귀를 다시 시작했다. 제품의 폴더 권한 검사는 완화하지 않았다. 브라우저 전체1113통과/1skip, 타입·빌드·Ruff·diff 검사는 통과했다.

최종 재실행: 전체Python **1036통과/기존경고2,143.05초**. 현재 진행 중인 개발은 없으며 다음 작업과 사용량 제한은 최상위 인수인계를 따른다.
