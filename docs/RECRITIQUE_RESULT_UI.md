# 새 AI 재검토 결과의 화면 복귀

구현일: 2026-09-13. 기존 MUI/PDF 검토 화면에 로컬 JSON 결과 가져오기를 추가했다.
전체 계획 추정: 본선용 약 50%, 기업 도입 약 25%. [기준](COMPLETION_ESTIMATE.md).

## 사용 흐름

1. 같은 PDF와 저장한 이력 JSON으로 검토를 준비하거나 복구한다.
2. [로컬 AI 재검토](FIELD_RECRITIQUE.md)를 실행한다. 웹의 버튼이 모델을 실행하는 것은 아니다.
3. **수정 후 AI 의견 → AI 재검토 결과 불러오기**에서 `output/recritique/<run-id>/report.json`을 선택한다.
4. 관측값 오류 의심과 비교 근거의 한계를 구분해 읽는다. 관측값 버튼으로 편집 영역에 돌아간다.
5. AI가 참조한 원문 문구를 펼쳐 페이지/전체 문구를 확인하고 원문 위치를 연다.
   모델이 특정 필드를 지목하지 않았으므로 단어/필드 단위 근거를 만들어 붙이지 않는다.
6. 사용자 값을 바꾸거나 확인 이력을 추가했다면 새 이력으로 다시 실행한다.

사용자 판단·로컬 규칙 검사·새 AI 의견·최초 모델 의견을 서로 다른 기록으로 표시한다.
AI 의견상 보류는 사용자 보류를 자동 설정하지 않는다. 비교 제한은 개별 관측값을 자동 제외하지 않는다.
AI 쟁점이 없어도 과거 쟁점 해결, 임상 정확성, 비교 가능성 또는 승인을 뜻하지 않는다.

## 입력 검사

- 8 MiB/깊이 30/파서 노드 500,000의 bounded JSON reader. 중복 키·prototype 관련 키·잘못된 JSON을 거부한다.
- `field-recritique/1`, prompt version 1, 미승인·미인증·사용자 값 미변경 플래그와 지원 실행 모드를 검사한다.
- 중첩된 규칙 결과를 기존 결과 reader로 검사한다: PDF hash/페이지/문구/전체 검토/실제 규칙 입력/제외/차분 일치.
- 전체 검토 내용 hash와 실제 재구성한 AI 요청 payload hash를 계산해 대조한다.
- 후보 집합은 규칙 결과와 같아야 한다. 새 쟁점의 관측값과 문구는 해당 후보/입력에 존재해야 한다.
- 모델 쟁점 목록을 다시 만들어 출력 finding 목록과 대조하고 보류/남은 초안 집합을 다시 계산한다.
- 단일 호출/수정 없음/예산·사용량·상태를 대조한다. 실패·예산 초과·후보 없음에는 완료된 의견을 표시하지 않는다.
- 현재 이력이 바뀌거나 미기록 편집 중이면 이전 쟁점·집계·질문을 숨긴다. 진행 중 파일 읽기도 버전이 바뀌면 폐기한다.
- 잘못된 결과를 불러와도 기존 사용자 검토/이전 결과를 덮어쓰지 않는다.

이 검사는 **파일 내부 일관성 검사**다. 일관되게 위조한 파일의 실행 진위/작성자, 모델/규칙의 정확성,
프롬프트 최신 여부, 실제 사용량/과금/구독 잔여량을 인증하지 않는다. 입력 문구에 없는 문맥은 보완하지 않는다.
PDF를 새로 독립 해석하거나 새 모델 호출·파일 업로드·자동 저장을 수행하지 않는다.

## 검증

웹 311개(신규 61개), Python 322개 회귀 검사 및 TypeScript/production build 통과.
새 테스트는 실제 Python producer가 만든 합성 자료/스크립트 결과를 웹에서 읽어 정상·실패·예산·후보 없음,
위조/불일치 입력, 보류·비교 제한 구분, 복구/파일명 변경, 이전 버전 숨김과 원문 참조를 검사한다.
Node 테스트에도 부모 프로젝트의 `uv`/Python 환경이 필요하다.

지난 단계 실제 Codex 실행 `aa82b1fd-6e4d-4721-ae4f-07638db45909`의 저장 결과를
복구된 검토와 새 웹 reader로 다시 읽어 후보 3개 유지·비교 제한 2개를 확인했다.
이는 합성 자료의 저장 응답 회귀 검사이며 이번에 모델을 새로 호출한 것은 아니다.

기존 개발 서버 HTTP 200 확인. 실제 브라우저 클릭·스크린샷·키보드·모바일/접근성 QA와 임상 평가는 미수행이다.
Sites 스킬에 따라 기존 MUI·로컬 처리를 유지했고 의존성·인증·공유 권한을 변경하지 않았다.
기존 사이트 배포·GitHub commit/push·모델/대회 API 호출은 하지 않았다.
