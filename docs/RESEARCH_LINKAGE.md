# 시험·코호트 연결 사전 점검

2026-09-16. 수집한 자료를 개별 시험의 결과로 잘못 옮기지 않도록, 사람이 먼저 확인할 지점을 표시한다.
이 기능은 저장된 제목·문구·연결 메타데이터를 사용하는 결정적 규칙 검사다. AI 의미 해석이나 임상적 동일성 판정이 아니다.

## 사용 흐름

약물 수집 기록 → 시험 선택 → 최근 다중 출처 조사 열기 → ‘시험·코호트 연결’.
분류별 필터에서 ‘대조 문구와 확인 질문’을 펼치고 ‘원문 근거·검토 이력 확인’으로 해당 자료를 검토한다.
별도 연결 점검 JSON과 기존 검토·KOL Markdown에 점검 내용을 저장한다. 원본 및 AI 초안은 그대로 보존한다.

| 분류 | 의미 |
| --- | --- |
| 선택 NCT 문구 발견 | 확보한 제목·문구에 선택 NCT만 등장. 해당 결과의 귀속/동일 코호트 확인은 아님 |
| 여러 NCT 문구 발견 | 서로 다른 NCT가 두 개 이상 등장. 선택 NCT가 포함되지 않을 수도 있음 |
| 다른 NCT만 발견 | 다른 NCT 하나만 등장. 별도 시험의 결과가 섞이는지 확인 필요 |
| 등록부 연결 · 본문 확인 필요 | 선택 NCT 문구는 없지만 등록 레코드/문서/결과 인용 연결이 존재 |
| 약물 단위 규제 문서 | 규제 문서는 NCT 언급 유무와 무관하게 약물 허가 단위 자료로 우선 표시 |
| 시험 연결 문구 미확보 | 위 기준의 명시적 연결 미확보. 자료가 무관하다는 결론은 아님 |

## 경계와 감사 가능성

- 제목·수집 문구만 검사한다. 검색어·URL·AI 해석에 들어 있는 NCT는 근거로 쓰지 않는다.
- NCT 대소문자를 정규화하되 정확한 식별자 경계를 검사한다. 지정된 통합 분석·하위집단·코호트·증량/확장 표현도 표시한다.
- 각 자료의 출처 ID/SHA-256, 선택 NCT, 발견 식별자, 최대10개의 짧은 대조 문구와 확인 질문을 남긴다.
- 부정문 속 식별자도 ‘언급’이다. 문장 의미/논문 결론/약물 별칭을 판정하지 않는다.
- PDF 본문·표·각주 판독은 포함하지 않는다. 같은 NCT라도 암종·치료 차수·분모·자료마감일이 다를 수 있다.
- 자동 포함/제외, 전문가 인증, 모델 실행, 설계 계산 차단 해제를 하지 않는다. `clinicalVerified:false`로 내보낸다.
- 규칙 버전 `TEXT_METADATA_RULES/1`, JSON 스키마 `research-linkage-audit/1`. 저장 원문을 바꾸지 않는 파생 화면이다.
