# 자료에서 설계 비교까지 · 대표 합성 사례

2026-09-17. 진입: 첫 화면 `보유 자료로 검토` 또는 좌측 `설계 검토`.
실제 PDF/CSV 검토는 이 화면 상단 `PDF·CSV 검토`로 유지한다.

## 실행 순서

1. `합성 사례로 시작`: TB-DEMO-01 / DEMO-P02 v1 / 현재 군당30명, 변경 군당60명.
2. 실제 규칙 대조: B 이상반응 요약10/50=20%, 합성 원자료10/40=25% 불일치.
3. `차이 확인 · 원자료 기준 가상 비교`: 자동 수정·임상 승인 없이 사용자가 계산 진행 선택.
4. 기존 Python `/api/reviews`로 두 설계×두 가정×10,000회 계산. 가짜 대기 없음.
5. 현재안/변경안, 원자료 비율 가정/독성 스트레스 전환.
6. `KOL 회의 브리핑`: 출처 행·입력 가정·실제 계산에 연결된 규칙 기반 질문3개.
7. Markdown 브리핑, 사례 입력 JSON, 계산 기록 JSON 내려받기.

자료 입력은 엄격한 `decision-case/1` 합성 JSON만 허용(64KiB). 예제 JSON 내려받기 지원.
실제 PDF를 읽어 AI가 설계안을 만든 기능이 아니다. 별도 공개 근거 조사 결과를 몰래 넘기지 않는다.

## 계산 및 진실성 경계

- 합성 원자료의 반응 A/B15/50,16/50; 이상반응6/50,10/40을 가상 확률로 대입.
- 독성 스트레스55%/65%, 한계35%, 가중치0.7은 별도 명시된 합성 가정이다.
- 군당30/60명은 제공된 프로토콜의 시연 대안이며 추천 표본수·AI 생성 설계가 아니다.
- 원자료 비율 대입은 모수 불확실성 추정이 아니다. 이상반응의 정의·시점·집단은 군 간 일치해야 계산 가능.
- 요약 불일치는 확인 전 계산 차단, 집단/시점/정의 차이는 확인 버튼으로도 우회 불가.
- 엔진 응답은 입력·표본수·반복·seed·네 조합·확률 합·MC 표준오차까지 검사한다.
- 기존 API의 고정 evidence_input/checked_claims는 이 사례의 증거로 사용하거나 내보내지 않는다. 시뮬레이션만 사용한다.
- 새 외부 모델 호출0. 모든 대조·의제·질문은 규칙 기반, MOC 표시 유지.
- 임상 승인·권장 용량·성공/허가 확률·검정력·비용/기간 계산 아님.
- 서버 영구 저장/결과 재가져오기는 미구현. 사례 입력만 다시 열 수 있다. 결과는 내려받아 보관.

## 남은 핵심

실제 PDF/등록 결과의 검토된 필드 → 출처 있는 AI 제안 가정 → 승인 전 계산 연결은 여전히 남는다.
이 화면은 대표 합성 사례의 전체 동선이며 위 기능 완료를 뜻하지 않는다.
Remotion 최종 영상, 실제 공개 사례의 독립 임상·통계 검토도 남는다.

## 로고

`web/public/brand/trialboard-original.png`: 사용자 원본 복사, 원본 파일 미변경.
`trialboard-symbol.png`, `trialboard-wordmark.png`: 내장 imagegen 편집으로 분리한 투명 PNG.
생성 편집본이므로 원본 픽셀의 무손실 크롭과는 구분한다. 원본 외부 여백은 UI 프레임에서 처리.
사이드바·상단 BrandLogo 컴포넌트, 좁은 사이드바는 심볼, favicon은 심볼을 사용.

- 워드마크: 기존 `TrialBoard` 글자만 분리, 심볼 제거, 철자/글자형/자간/파란색 유지, 투명 배경, 새 디자인 금지.
