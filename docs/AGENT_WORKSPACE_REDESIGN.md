# Agent-first 화면 개편 · 2026-09-17

## 실제 앱에서 보기

로컬 `http://127.0.0.1:5173/`. 이전 `8769`는 디자인 목업이며 실제 작업 화면이 아니다.
오른쪽 위 **발표 보기**는 사이드 메뉴와 보조 동선을 숨긴다. 다시 누르면 복원한다.
설정 변경·AI 호출·결과 수정은 하지 않는다.

## 변경

- 따뜻한 화이트·세이지, DM Sans/Noto Sans KR, 기존 MUI 입력·버튼 유지. 세리프 없음.
- 입력: 약물명/NCT 한 칸, 고정된 현재 검토 목적, 별도 공개 정보 전송 동의.
  자유형 지시를 이해하는 채팅으로 가장하지 않는다. 보유 자료 검토는 기존 별도 경로다.
- 실행: 요청 요약, 8단계 작업 경로, 현재 작업을 크게 표시, 실제 수신 자료/구조화 항목/후속 조사 계획.
  상세 로그는 접어 둔다. 경과 시간은 실제 시간이며 예상 완료 시간이나 성공률이 아니다.
- 단계가 넘어갔다는 사실과 성공을 구별. 이전 진행 표시가 계속 도는 문제를 방지한다.
  현재 작업 이벤트가 없어도 꾸며낸 자료·생각·진행률을 넣지 않는다.
- 결과: 판단 범위·근거 상태·다음 판단을 우선하고, AI 첫 쟁점과 회의 질문을 표시한다.
  가상 설계는 `가상 설계 · MOC` 탭으로 분리. 근거 부족·미검증·저장 기록 표시는 유지.
- 화면 전환 때 작업공간 상단으로 이동. 기존 원문/인용/기록 복구/보고서/수동 경로 보존.
- Sites UI 지침의 작업공간 중심 구성·반응형·실제 화면 QA를 적용했다. 기존 React/Python 구조는 유지하며 새 호스팅으로 이관하지 않았다.

## Remotion 연결 준비와 남은 작업

루트 `data-demo-scene` 값: `input`, `running`, `scope`, `loading`, `result`, `error`.
`data-presenting`과 `AgentActivity`를 장면/확대 타깃으로 사용할 수 있다.
현재는 **실제 앱 개편**이다. Remotion 설치, Composition, 영상 렌더링은 아직 하지 않았다.

다음 영상 작업:

1. 최종 시연 사례·범위를 고르고 실제 입력→결과 완주를 다시 확인한다.
2. 원본 실행 이벤트/출처/결과를 보존하는 읽기 전용 캡처 데이터를 만든다.
3. 동일 UI 컴포넌트로 Remotion 장면을 구성한다. 타이핑·현재 단계 확대·근거 등장·결과 강조 중심.
4. 지연 시간 축약은 영상 편집으로 명시한다. 재생을 LIVE로 표기하거나 합성 결과를 실제처럼 사용하지 않는다.
5. 1080p/한글 가독성/클릭 강조/무음 구간/자막/MOC 표기를 검수한다.

## 이번 검증 범위

- 웹 테스트 889개 통과, TypeScript/Vite build 통과.
- Vite의 Node 22.9 버전 경고와 큰 번들 경고는 남아 있다. Node 22.12+ 환경 확인 필요.
- 실제 브라우저: 1440px 입력/실제 저장 결과 복구/발표 보기, 390px 입력·결과 배치 확인.
- 실제 `sotorasib` 공개 검색 → 72건 중20건 확보 → 범위 확인 대기 전환 확인.
  이번 QA에서 새 유료 모델 호출은 하지 않았다. 이후 모델/원문 처리/최종 결과까지 새 완주는 미실행.
- 중단 상태·복수 활성 상태 방지는 자동 검사. UI 중단 버튼을 누르기 전에 검색이 완료되어
  이번 브라우저에서 진행 중 중단 성공을 확인했다고 주장하지 않는다.
- 비밀키 변경·읽기·커밋·push·외부 배포 없음. 기존 작업트리 보존.

이는 임상 성능 개선 검증이 아니다. 전체 구현율의 기존 주관적 추정 78%(±10%p)는 유지한다.
근거 기반 AI 설계 생성·기업용 협업·독립 임상 검증은 여전히 별도 미완료다.
