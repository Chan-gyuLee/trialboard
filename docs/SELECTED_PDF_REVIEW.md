# 긴 PDF의 선택 페이지 검토 · 2026-09-22

## 사용 흐름

공개 조사 결과에 저장된 관측 추출이 있으면 **추출 근거로 검토 이어가기**를 누른다.
40쪽을 넘는 문서도, 조사 때 저장한 페이지를 원래 PDF 쪽수 그대로 필드 검토로 연결한다.
예: 전체80쪽 → 저장된48·73쪽 연결 → 인용 클릭 시 원문48쪽 표시 → 설계·회의 검토.
짧은 문서의 기존 전체 페이지 경로와 이전 프로젝트 형식은 유지한다.

- 전체 쪽수, 연결한 쪽수, 작업에 포함하지 않은 쪽수를 따로 표시한다.
- 이전/다음 및 원문 쪽수 선택은 연결된 실제 페이지 번호를 사용한다. 빈 중간 페이지를 만들거나 쪽수를 다시 매기지 않는다.
- 파일 SHA-256, 실제 전체 쪽수, 선택 범위, 추출 문구·인용을 대조한다. 불일치 시 기존 검토를 유지한다.
- 모든 AI 추출 필드는 **미확인**으로 시작한다. 연결·페이지 이동은 사용자 확인이나 임상 검증이 아니다.
- 프로젝트 저장→새로고침→복구 후에도 같은 페이지·원본 추출·조사 맥락을 유지한다. 모델 전송 동의는 복구하지 않는다.
- 원문 메모, 규칙 재검증, 설계 비교의 내보내기에도 선택 페이지 범위·전문 미검토 한계를 남긴다.

## 기술 경계

새 검토 원문 계약 `pdf-evidence-selected/1`에 `totalPages`와 원래 번호의 `pages`를 저장한다.
기존 `pdf-evidence/1`은1부터 이어지는 최대40쪽이며 직렬화 형식이 변하지 않는다.
수집용 `pdf-evidence-window/1` 자체를 사람의 검토 기록으로 인정하지 않는다.
원본 PDF를 브라우저에서 다시 읽은 후에만 새 선택 페이지 계약을 만들고 인용을 연결한다.

최대200쪽 문서 중 저장된 최대40쪽, 수집 PDF 최대5,000,000바이트.
선택 페이지의 총 텍스트250,000자/항목20,000개 제한은 유지한다.
수동 파일 선택의 전체 읽기는 여전히40쪽 한도다. 임의 페이지 추가·전문 읽기·OCR·다문서 병합은 이번 작업 범위가 아니다.
계획문서만 있는 조사, 관측0개, 실패·중단 기록은 설계 근거로 자동 승격하지 않는다.
서버 재검증은 바이트 지문과 전달된 텍스트·인용의 내부 일관성 검사이며 독립 PDF 재추출·임상 검증이 아니다.
