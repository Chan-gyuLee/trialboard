# 재검증 결과의 화면 복귀

2026-09-13. 기존 MUI PDF 필드 검토 화면에 로컬 `field-revalidation/1` 결과 가져오기를 연결했다.
파일은 브라우저 안에서만 읽으며 Python·AI 실행, 서버 전송, 영구 저장은 추가하지 않았다.

## 사용 흐름

1. PDF 원문 확인 → 필드 검토에서 필요한 값을 확인·수정·보류한다.
2. 원문 export와 검토 이력을 내려받고 [로컬 재검증](FIELD_REVALIDATION.md)을 실행한다.
3. **같은 검토 화면을 열어 둔 상태로**, ‘수정 후 재검증 → 재검증 결과 불러오기’에서 생성된 `report.json`을 선택한다.
4. 현재 쟁점·추가·미발생·유지를 선택해 내용을 본다. 쟁점의 관측값/필드 버튼으로 해당 편집 영역으로 이동한다.
5. 특정 필드에 인용이 있으면 기존 PDF 원문 위치도 연다. 전체 비교 쟁점에는 단일 원문 위치를 만들어 붙이지 않는다.
6. 추가 수정 후에는 이력을 다시 내려받고 로컬 재검증을 반복한다.

재검증 결과만으로 검토 내용을 복원하거나 덮어쓰지 않는다. 새로고침했다면 같은 PDF와 이력 JSON으로
[저장한 검토를 먼저 복구](FIELD_REVIEW_RECOVERY.md)하고 당시 재검증 결과를 불러온다.
내려받기 전 기록하지 않은 편집값은 결과에 포함되지 않는다. 미기록 편집 중에는 결과 표시/가져오기를 제한하며 ‘편집 취소’로 마지막 기록값으로 돌아갈 수 있다.

## 화면의 안전 경계

- 현재 PDF hash, 보고서 입력의 페이지·문구 ID·텍스트, 현재 검토의 원래/현재 값·상태·이력을 대조한다.
- JSON 키 순서·들여쓰기는 무시하지만 검토 내용은 동일해야 한다. 내용이 다른 결과는 거부한다.
- 결과를 불러온 뒤 값·사유·이력을 변경하면 이전 결과의 쟁점과 집계를 숨긴다. 같은 값을 재확인해도 이력이 달라지면 재검증이 필요하다.
- 검토 내용을 보류 제외/미확인 결측 처리하여 예상 입력을 만들고 보고서의 실제 입력과 대조한다. 남은 관측값이 입력과 다른 값이거나 보류 관측값이면 거부한다.
- 관측값/필드 참조, 중복, 상태 플래그, 현재·기준 쟁점에서 계산한 차분의 일관성을 검사한다.
- 8 MiB/JSON 깊이 30/노드 500,000 제한. 중복·원형 오염 키를 거부하며 실패한 가져오기는 기존 결과와 검토를 덮어쓰지 않는다.
- 실행 시 지정한 시험·질문을 표시한다. 다른 질문을 현재 질문인 것처럼 숨기지 않는다.

이것은 **파일 내부 일관성 검사**다. Python 규칙의 정확성이나 실제 실행 진위를 브라우저에서 인증하지 않는다.
보고서의 raw 입력 파일 hash를 원래 파일과 다시 대조하는 기능은 없으며, 현재 검토와의 연결은 내장된 검토 내용의 동등성으로 확인한다.
규칙 코드 hash는 식별 정보이지 승인된 버전·최신 버전의 증명은 아니다.
`accepted`는 화면에서 ‘남은 관측값 · 미승인’으로 표시하고, 쟁점 0건도 임상적 정확성·비교 가능성을 뜻하지 않는다고 안내한다.
‘미발생’에는 자료 제외로 검사 대상이 줄어든 경우도 있으므로 ‘해결’로 표시하지 않는다.
이전 AI 쟁점은 별도 과거 기록으로 남기며 AI 반론 재실행이나 설계 계산을 수행했다고 표시하지 않는다.

## 검증

- 웹 **187개** 테스트: 기존 149개 + 결과 가져오기/상태/참조/차분/오래된 결과 차단 38개.
- Python **294개** 회귀 테스트. 이번 단계에서 Python 구현은 변경하지 않았다.
- `node scripts/check-field-review-bridge.mjs`에서 실제 웹 함수 → Python 재검증 → 웹 결과 읽기 왕복 검사.
  합성 사례의 수정 후 4개·보류 후 3개 보존, 수정된 이력에 이전 결과 가져오기 거부를 확인했다.
- Node 24 TypeScript 및 production build 통과. 개발 서버 HTTP 응답 확인.
- 실제 브라우저 클릭·스크린샷·키보드·모바일/시각 QA는 수행하지 않았다. 함수 왕복 검사는 UI 조작 테스트가 아니다.
- 기존 번들 경고와 Python 의존성 경고는 남아 있다. Sites 스킬로 기존 MUI/로컬 자료 처리 구조를 유지했다.

이번 변경은 로컬 소스다. 기존 사이트 배포·GitHub commit/push·모델 호출·대회 토큰 사용은 하지 않았다.

## 다음 작업

1. 검토 이력 재불러오기/복구는 [후속 구현 완료](FIELD_REVIEW_RECOVERY.md). 자동 저장·인증된 협업은 별도다.
2. 변경 근거에 대한 제한된 AI 반론 재실행. 사용자 수정값을 보존하고 규칙 검사와 AI 의견을 분리한다.
3. 실제 브라우저 사용성 검증과 표 머리글·각주·다중 문구 근거 묶음, 독립 전문가 평가.
