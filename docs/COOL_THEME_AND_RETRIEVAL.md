## 화면

사용자 요청에 따라 세이지/웜 화이트를 쿨 화이트·잉크 네이비·코발트 블루로 교체했다.
공통 CSS 토큰과 MUI 테마, 실행/조사/결과 CSS Modules를 함께 수정했다.
실행 헤더는 네이비, 현재 단계·버튼·수치·검색 링크는 블루, 근거 부족은 앰버,
MOC 비교는 바이올렛으로 구분한다. 레이아웃·기존 기능은 유지했다.
Sites 디자인 지침의 가독성/일관된 테마 원칙을 적용했으며 기존 React/Python 앱을 유지했다.
새 사이트 등록·외부 배포·커밋/push는 하지 않았다.

대표 색상 계산 대비: 본문/흰색15.86:1, 보조본문/흰색5.72:1,
블루/옅은블루5.27:1, 흰버튼글씨/블루5.91:1, 헤더 보조글씨/네이비8.54:1.

## 실제 수집 변경

- 약물명·등록부 인용 검색: 최대1페이지/20건.
- 선택 시험번호·AI 후속 검색: 최대2페이지/40건.
- Europe PMC의 cursorMark/nextCursorMark를 고정 허용 API에 매개변수로 전달한다.
  외부 URL을 커서로 실행하지 않는다. API 기본 정렬을 사용한다.
- 페이지가 수신되면 즉시 실제 DB 집계·출처 카드를 전달한다. 가짜 작업이나 인위적인 지연 없음.
- coverage에 pages/stop_reason을 저장하고 실시간·결과·기록 재생·보고서에서 표시한다.
  기존 기록에는 새 상세를 만들어 붙이지 않는다. null/누락 필드는 이전 계약과 호환된다.
- 종료 사유: 응답상 결과 끝, 페이지 한도, 출처100개 한도, 커서 없음/반복,
  중복 페이지, 요청 실패. 다음 페이지 실패 시 이전 수신 자료·수치를 보존하고 PARTIAL 처리.
- 검색 응답 건수에는 중복/비대상 항목이 포함될 수 있다. DB 고유 출처 수와 다르며 검색별 total은 합산하지 않는다.
- 문헌 요청은 최대로 초기4회 + 후속4회 =8회. 등록부/FDA 각각1회 및 앞단 시험검색은 별도.
  요청당20건/4MB, 전체 출처100개, 조사 실행240초 한도는 유지.
  조사 모델2회, 계획24개 발췌/최종 검토8개도 유지. 한도 때문에 실제 요청 수는 더 적을 수 있다.
- 수집 대상은 여전히 초록/메타데이터/PDF 링크다. 이번 변경은 논문 전문 확보·전수조사·임상 검증이 아니다.

규격 확인: [Europe PMC REST API](https://europepmc.org/RestfulWebService),
[Europe PMC 팀의 cursorMark 안내](https://groups.google.com/a/ebi.ac.uk/g/epmc-webservices/c/V-15Coxlle8).
