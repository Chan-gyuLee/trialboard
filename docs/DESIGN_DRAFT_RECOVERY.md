# 작성 중 설계 초안 저장·복구

2026-09-14. 완성 전 입력을 잃지 않기 위한 로컬 파일 보관 기능이다. 자동 저장이나 계산 결과가 아니다.

## 사용 순서

1. ‘설계 비교·KOL’에서 일부 질문·표본수·가정을 작성한다.
2. ‘작성 중 초안 저장’을 누른다. 빈칸·공백·미완성 숫자 문자열도 그대로 보관한다.
3. 필드 검토가 있으면 해당 ‘이력 JSON’도 별도로 내려받는다.
4. 다음에 같은 PDF와 저장 당시 필드 검토를 복구하고 ‘설계 입력 복구’에서 `design-draft.json`을 선택한다.
5. 입력을 완성한 뒤 계산용 JSON을 내보내거나 별도 동의로 로컬 계산을 실행한다.

빈 검토에서도 초안을 보관할 수 있다. 이 경우 같은 PDF를 다시 열어 바로 복구한다.
기존 `design-brief.json`도 같은 복구 버튼으로 읽을 수 있다.

## 계약과 한계

- `design-draft/1`: `UNVALIDATED_DRAFT`. 문자열을 보관하며 계산용 reader는 거부한다.
- `design-brief/1`: 필수값·숫자 범위·근거 연결 검사를 거친 계산 입력. 계산 완료나 임상 승인이 아니다.
- PDF SHA-256과 전체 필드 검토 내용 hash에 결합한다. 다른 문서·검토 버전은 거부한다.
- 구조·길이·배열 크기·ID 중복·관측값 연결·UTF-8 100,000바이트 한도를 검사한다.
- 복구 실패 시 기존 입력을 바꾸지 않는다. 교체 확인과 비동기 버전 검사를 유지한다.
- PDF 원본, 필드 검토 이력, 계산 결과, KOL 메모는 포함하지 않는다. 용량·관측값 ID와 작성 문구는 포함한다.
- 작성자 인증, 가정 수정 계보, 서버/브라우저 자동 저장은 제공하지 않는다.
- 이전 결과의 현재성 검사를 유지하며, 초안 복구가 새 계산을 수행하지 않는다.

## 검증

신규 19개: 빈/부분 초안 왕복, 문자열 보존, 계산용 reader 차단, 다른 PDF/검토 거부,
형식·크기·중복·차원·관측값 오류, 기존 계산용 입력 호환. 웹 전체 447개·production build 통과.
실제 브라우저 저장/복구 클릭은 파일 선택창 제어 문제로 아직 미검증이다.
