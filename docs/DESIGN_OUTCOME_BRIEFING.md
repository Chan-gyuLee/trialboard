# 설계 결과 브리핑과 직전 계산 비교

2026-09-22 · 로컬 제품 개발. 영상·배포·새 모델 호출 없음.

## 이번 변경

`자료 검토 → PDF 원문 확인 → 04 설계 비교·KOL → 결과 비교`의 기존 표 중심 결과를 개편했다.

- 네이비 요약: 계산 또는 보류 상태, 설계/가정/반복 수, 판단 범위.
- 가정 탭: 추가 참여자, 가정상 올바른 선택·보류 차이, 가정상 한계 초과군 선택 차이.
- 기준/대안 카드: 총 인원과 군당 인원, 선택·보류 빈도, Monte Carlo SE.
- 원문 연결: 계산 가정과 관측ID별 원문 이동을 접어서 제공.
- 다음 회의: 현재 가정에 연결된 기존 규칙 기반 질문과 KOL 회의 이동.
- 계산 완료·결과 탭 진입 시 제목으로 포커스/스크롤 이동. 준비·파일 복구 안내는 결과에서 접는다.

계산 엔진·근거 검증·AI 제안 확인 규칙은 바꾸지 않았다. MOC 표시는 유지한다.
확률의 막대는 실제 계산값이며 임상 효능·검정력·허가 가능성을 표시하지 않는다.
모든 군의 가정상 이상반응확률이 한계를 **초과**한 경우에만 안전 한계 초과 설명을 표시한다.
한계와 같은 값은 초과가 아니다. 최선 설계나 실제 약물의 안전성을 판정하지 않는다.

## 바꾼 입력, 달라진 결과

입력을 수정해 로컬 계산을 다시 실행하면 직전 결과와 현재 결과를 비교한다.
변경된 인원·확률·가중치·안전 한계·질문·원문/검토/엔진 식별값·seed·반복 수·이름/이유/순서를 기록한다.
AI 확인 digest 변경 자체는 가정 변경으로 세지 않는다.

같은 원문·검토 버전·질문·용량군/관측 연결·엔진이고 양쪽 계산이 완료됐을 때만
동일한 가정ID/설계ID를 연결해 세 지표의 이전/현재/%p 차이를 표시한다.
조건이 다르거나 한쪽이 보류이면 이유와 입력 변경만 표시한다. 인과효과/유의성 검정은 아니다.

`변경 요약 저장`으로 두 실행ID·입력 변경·세 지표의 전후값을 Markdown으로 내려받는다.
이는 **현재 탭 메모리의 직전 1회 비교**이며 새로고침을 넘기는 전체 버전 저장/복구가 아니다.
기존 회의 JSON을 별도로 보관해야 한다. 이전 결과/회의 JSON을 불러오면 직전 비교를 초기화한다.
