## 다시 시연하기

기존 로컬 서비스 `uv run python -m trialboard.api --enable-designs --enable-agent-demo`와 Vite5173 필요.
‘시연 녹화’는 개발 화면에만 표시된다. 버튼 → **현재 TrialBoard 탭** 허용 → 시연 → 녹화 종료 → 영상 저장.
최대 10분/약250MB, 무음, 브라우저 메모리 보관. 종료 전 영상을 내려받아야 한다.
다른 탭을 선택하지 않는다. 전체 화면·창 캡처를 선택하면 녹화를 거부한다.
공개 페이지의 공식 Screen Capture API 사용: [탭 선택 옵션](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia).
