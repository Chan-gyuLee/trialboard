## 첫 실행 가능한 검토 흐름

네트워크와 API 키 없이 합성 자료의 정상·오류·결측 경로를 실행합니다.
기존 수집·이력 코드와 의존성을 제거한 독립 실행 경로입니다.
로컬 웹과 실행 API를 연결했습니다. 배포된 정적 미리보기의 원격 실행,
실시간 LLM·PDF 의미 검증은 아직 포함하지 않습니다.

```bash
uv sync
uv run python -m trialboard.review --mode normal
uv run python -m trialboard.review --mode denominator-error
uv run python -m trialboard.review --mode missing-evidence
uv run pytest
```

`output/review/`에 입력 JSON, 구조화 보고서 JSON, 읽기용 Markdown을 생성합니다.
같은 이름의 출력은 재실행 시 갱신됩니다. 원본 자료는 변경하지 않습니다.

현재 검증 항목은 source hash·버전·레코드 참조, 약물·환자군·관찰기간 문맥,
사건 수·분모 일치, 상충과 결측, 고정 seed 계산입니다. 원문 의미나 임상적 타당성을
검증했다고 표시하지 않습니다. 합성 시나리오 계산으로 자료 결측을 채우지 않습니다.

설계 비교는 각 군 30명 또는 60명의 사전 정의 예제입니다. 반응과 이상반응의 독립
Bernoulli 모수, 가정한 효용함수와 한계값으로 용량군 선택 빈도를 계산합니다.
DROID·MERIT 구현, 우월성·비열등성 검정, 임상적으로 권장하는 표본수가 아닙니다.
모수·규칙·Monte Carlo 표준오차·실행 환경을 보고서에 함께 기록합니다.

## 입력을 바꾸는 로컬 API

```bash
uv run trialboard-api --port 8000
```

실행 후 `http://127.0.0.1:8000/docs`에서 호출할 수 있습니다. 용량군별 합성 확률,
두 비교 표본수, seed·반복·오류 모드를 바꾸면 서버가 재검증·재계산합니다.
실제 임상자료 입력이나 영구 저장 기능은 없으며 외부 공개용 서버가 아닙니다.
요청 예시·제한·재현 방법은 [API 문서](docs/API.md)에 있습니다.

별도 터미널에서 `cd web` 후 최초 `npm ci`, 이어서 `npm run dev`를 실행하면 로컬 검토 화면과 연결됩니다.
Node 24를 사용합니다. 화면 구조와 로컬·배포 동작의 차이는 [웹 안내](web/README.md)에 있습니다.

실제 임상자료를 사용하는 다음 단계의 설계 검토 항목은
[FDA 용량 최적화 지침](https://www.fda.gov/media/164555/download)을 참고하되,
이 프로토타입이 지침 적합성이나 규제 승인을 입증하는 것은 아닙니다.
