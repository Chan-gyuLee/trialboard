# TrialBoard

표적항암제의 용량 비교시험을 준비하는 **근거 기반 설계 검토 작업공간**입니다.
약물 검색 → 공개 근거 수집 → PDF 원문·AI 초안 검토 → 가정별 설계 비교 → KOL 질문·회의 기록을 연결합니다.

제4회 JUMP AI 본선 준비용 연구 프로토타입입니다. 임상적 의사결정·규제 승인·권장 용량을 제공하는 제품은 아닙니다.

## 현재 상태 · 2026-09-16

제안서 전체 범위 기준 **약 77%**, 기업 도입 수준은 기존 좁은 파일럿 범위 기준 약 25%로 추정합니다.
계획에 따른 주관적 추정(오차 최소 ±10%p)이며 테스트 통과율이나 임상 정확도가 아닙니다.
[진행률 산정 기준](docs/COMPLETION_ESTIMATE.md) · [다음 작업](docs/NEXT_TASKS.md)

이 README는 최신 저장소 코드 기준입니다. **GitHub 업로드는 웹사이트 배포가 아닙니다.**
친구도 저장소를 받아 아래처럼 자기 컴퓨터에서 실행할 수 있습니다. 비공개 저장소라면 GitHub 접근 권한이 필요합니다.

## 빠른 시작

### 1. 준비 및 설치

- Git, **Node.js 24**, npm, [uv](https://docs.astral.sh/uv/getting-started/installation/)가 필요합니다.
- Python은 **3.12**를 사용합니다. uv가 필요한 Python과 의존성을 준비합니다.
- 검증한 환경은 macOS입니다. 개인 Codex 연결만 POSIX 환경으로 제한됩니다. Windows/Linux/WSL의 제품 전체 동작은 별도 검증이 필요합니다.

아래 명령은 저장소 루트에서 실행합니다.

```bash
git clone https://github.com/ryullee-hideandseek/trialboard.git
cd trialboard
uv sync --locked
npm --prefix web ci
```

### 2. 백엔드 실행 — 터미널 1

```bash
uv run python -m trialboard.api \
  --enable-designs \
  --enable-agent-demo \
  --enable-pdf-agent \
  --enable-evidence-scout
```

각 옵션은 설계 계산, 고정 사례 AI 실행, 선택 PDF AI 실행, 공개 근거 조사·프로젝트 저장 기능을 켭니다.
**서버를 켜는 것만으로 모델을 호출하지 않습니다.** 실제 모델 실행에는 화면에서 별도 동의가 필요합니다.

### 3. 화면 실행 — 터미널 2

두 번째 터미널에서도 같은 저장소 루트로 이동한 후 실행합니다.

```bash
npm --prefix web run dev
```

브라우저에서 **http://127.0.0.1:5173** 을 엽니다.
백엔드는 http://127.0.0.1:8000, API 설명은 http://127.0.0.1:8000/docs 입니다.
사용 중에는 두 터미널을 모두 켜 두고, 종료할 때 각각 Ctrl+C를 누릅니다.

5173/8000 포트는 현재 로컬 연결에 사용됩니다. 충돌하면 다른 포트로 임의 변경하기보다 기존 TrialBoard 실행 여부를 먼저 확인하세요.
외부 공개 서버로 열거나 인증 없이 인터넷에 노출하지 마세요.

### 4. 실제 AI 실행 — 대회 API

**코드를 개발하는 Codex 계정과 제품 에이전트의 사용량은 별개입니다.**
현재 제품 실행 기본값은 대회 API(`dacon`), 모델은 `gpt-5.6-terra`입니다.
MOC 예제·원문 검토·로컬 설계 계산에는 모델 키가 없어도 됩니다.

실제 AI를 쓰려면 터미널 1의 서버를 종료한 뒤 아래 명령으로 다시 시작합니다.
키 입력은 화면에 표시하지 않고 프로세스 메모리에만 보관합니다. 키 값이 명령 이력이나 파일에 들어가지 않습니다.

```bash
uv run python -m trialboard.api \
  --agent-provider dacon --prompt-dacon-key \
  --enable-designs --enable-agent-demo --enable-pdf-agent --enable-evidence-scout
```

또는 서버 환경에 `TRIALBOARD_DACON_API_KEY`를 안전하게 설정한 뒤 `--prompt-dacon-key`를 생략합니다.
환경변수 파일은 자동으로 읽지 않습니다. **키를 코드·README·Git·프런트엔드에 넣지 마세요.**
서버를 종료하면 비표시 입력한 키는 사라지므로 다음 실행 때 다시 입력합니다.

모델 변경은 `TRIALBOARD_DACON_MODEL`로 지정하며 메일에 안내된 `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`만 허용합니다.
화면의 실행 모델 안내에서 **대회 API / 팀 공용 토큰**을 확인한 뒤 자료 전송에 동의하세요.
인증 실패·한도 초과에도 개인 Codex나 다른 공급자로 자동 전환하지 않습니다.

한 번의 소량 연결 검사도 가능합니다. 팀 토큰을 소비하며 합성 입력만 보냅니다.

```bash
uv run python -m trialboard.agent.dacon_smoke --allow-external --prompt-key
```

대회 키는 승인된 팀원만 사용하세요. 친구가 팀 외부인이라면 키를 공유하지 말고 MOC로 체험하거나 아래 개인 Codex 경로를 명시적으로 선택합니다.
[연결 규격·오류·사용량 안내](docs/DACON_RUNTIME.md)

## 처음 무엇을 눌러 보면 되나요?

### AI 없이 전체 흐름 체험 — MOC

1. 첫 화면에서 보유한 PDF를 여는 흐름으로 이동해 **MOC 예제 PDF 열기**를 선택합니다.
2. **필드 검토**에서 **MOC 추출 기록 열기**, 이어서 **MOC 검토 예제 이어가기**를 선택하고 교체 안내를 확인합니다.
3. **설계 비교·KOL**에서 **MOC 설계 가정 열기**를 선택합니다. 원본 추출 연결이 필요하면 함께 제공된 `web/public/data/moc/original-agent.json`을 사용합니다.
4. 입력과 로컬 전송 동의를 확인한 뒤 계산합니다. 가정·표본수별 결과와 KOL 질문을 보고 메모를 기록합니다.
5. 회의 Markdown/JSON을 내려받거나 프로젝트를 저장하고 다시 열어 봅니다.

합성 자료 구간은 화면에 **MOC**로 표시됩니다.
추출·확인 기록은 스크립트/자동 테스트 예제이고, 설계 계산은 Python에서 실제로 수행합니다.
새 모델 실행이나 전문가 승인으로 소개하면 안 됩니다.
[상세 시연 기록](docs/MOC_DEMO_RECORDING.md) · [프로젝트 저장·복구](docs/PROJECT_CHECKPOINTS.md)

짧은 발표 흐름만 보려면 별도 **의사결정 브리핑**에서 근거 수정 대조 → 합성 설계 비교 → 회의 질문을 체험할 수 있습니다.
[3분 시연 대본](docs/DEMO_SCRIPT_3MIN.md)

### 공개 자료로 실제 실행

약물명·개발 코드·NCT 입력 → 공개 검색 동의 → 시험 선택 → 다중 출처 조사 →
공개 PDF 명시적 다운로드 → 원문 문구 확인·선택 → 별도 AI 전송 동의 → 추출 초안·검증·반론 확인 순서입니다.

예를 들어 `sotorasib`으로 검색할 수 있습니다. 검색 결과·가용 PDF·응답 시간은 외부 서비스 상태에 따라 달라집니다.
초안은 사용자가 확인·수정·보류해야 하며, 부족한 근거나 해결되지 않은 쟁점이 있으면 설계 계산을 차단할 수 있습니다.
**약물명 하나만 넣으면 임상적으로 검증된 설계까지 전자동 완성되는 상태는 아닙니다.**

## 검증한 것과 아직 남은 것

2026-09-16 현재 Python **503개**, 웹 **751개** 테스트와 TypeScript/Vite 빌드·Ruff 검사를 통과했습니다.
MUI의 `use client` 번들 경고, 큰 청크 경고, 테스트 의존성 deprecation 경고는 남아 있습니다.

- **MOC 전체 흐름:** PDF → 필드 검토 → 실제 설계 계산 → KOL 기록 → 프로젝트 저장 → 서버/화면 재시작 후 복구를 확인했습니다.
- **실제 자료:** 공개 자료 수집과 기존 로그인 모델 실행을 확인했습니다. 대회 API 연결 상태와 별도 실행 검증은 [대회 실행 기록](docs/DACON_RUNTIME.md)을 참고하세요. 최근 FDA 26페이지 문서 검사는 초안 3개/채택 0개로 부분 보류되었습니다. 이를 실제 임상자료 전체 비교 성공으로 보지 않습니다.
- **남은 핵심:** 표의 분리된 숫자·단위/각주 처리, 같은 시험·코호트 연결 강화, 실자료 전체 비교·회의 완주, 키보드/실패 경로 QA, 최신 해설 시연 영상, 독립 전문가·통계 평가입니다.
- **기업용 후속:** 다중 사용자 인증·권한·팀 동기화·운영 보안·배포는 아직 미완료입니다. 프로토콜 변경 검토·규제기관 미팅 준비 전체 제품을 구현했다는 뜻도 아닙니다.

## 빌드·테스트·업데이트

저장소 루트에서 실행합니다. 웹 테스트 일부도 Python/uv를 사용하므로 양쪽 의존성을 먼저 설치하세요.

```bash
uv run pytest
uv run ruff check .
node --test web/tests/*.test.mjs
npm --prefix web run build
```

빌드는 `web/dist/`에 정적 파일을 만듭니다.
**빌드만으로 Python API·실제 AI·근거 DB가 배포되지는 않습니다.**
현재 로컬 연결은 5173 개발 화면과 8000 API 기준입니다. 친구의 전체 기능 체험에는 위 두 터미널 실행 방법을 사용하세요.

다음 변경을 받을 때는 본인 수정사항을 먼저 보관하고 실행 중인 두 서버를 종료한 뒤:

```bash
git pull --ff-only
uv sync --locked
npm --prefix web ci
```

설치가 끝나면 두 서버를 다시 실행합니다. `git pull`이 충돌하면 로컬 작업을 삭제하거나 강제 초기화하지 마세요.

## 데이터와 기술 구성

- 프런트엔드: React 19 · TypeScript · MUI · Vite · PDF.js (`web/`).
- 백엔드: Python 3.12 · FastAPI · NumPy · SQLite (`trialboard/`).
- API 키·인증 파일·로컬 DB·다운로드 자료·녹화 영상·빌드 결과는 Git에 올리지 않습니다.
- 새로 clone한 친구의 프로젝트 목록/수집 DB는 비어 있습니다. 기존 로컬 프로젝트가 자동 공유되지는 않습니다. MOC 예제는 저장소에 포함되어 있습니다.
- 공개·사용 허가된 비민감 자료만 사용하세요. 브라우저 원문 열기, 로컬 저장/계산, 외부 검색, 모델 전송은 서로 다른 동작이며 화면의 동의 범위를 확인해야 합니다.
